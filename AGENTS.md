# Habit tracker

Офлайн-трекер привычек. Без бэкенда, аккаунтов и сети. Личный проект.

## Стек
Expo SDK 57, TypeScript, expo-router, expo-sqlite, zustand,
expo-notifications (только локальные), react-native-reanimated, date-fns.
Стилизация: StyleSheet + constants/design-tokens.ts.

## Язык
Весь UI на русском. Код, комментарии и коммиты на английском.

## Правила
- Не добавляй зависимости без моего разрешения. Сначала спроси.
- Не меняй схему БД без миграции и без моего согласия.
- Не трогай файлы вне задачи текущего этапа.
- Цвета, отступы, радиусы, шрифты — только из design-tokens.ts.
- Стрики и статистика считаются из entries, не хранятся отдельно.
- Даты храним как строку YYYY-MM-DD в локальной таймзоне пользователя.
- Длинные списки — FlatList, не .map.
- Перед тем как сказать «готово»: npx tsc --noEmit должен пройти чисто,
  и приложение должно запускаться без warning в Metro.
- Не полагайся на память по Expo API, сверяйся с Expo Skills.

## Работа по этапам
План лежит в PLAN.md. Делаем строго по одному этапу за сессию.
В конце этапа — краткий отчёт: что сделано, что осталось, что сломалось.
